## 流程与范围

1. 首页定期卡／Accounts 账户列表的定期行 → TD1-02 定存主页；定存不单独占 Tab。主页选择金额、存期、可选用途 → TD2-02 金额页 → TD2-04 复核 → 认证 → TD2-05 结果。TD2-01、TD2-03、TD2-03a 都是页内半框，不另设必经整页。
2. 主页 My deposits → TD1-03 我的定存 → TD3-01 对应详情。详情可按状态编辑展示名称与图标、修改到期处理、查看证明或提前取出。
3. 存款证明由服务端生成，App 预览、分享与保存；证明二维码／App 验真链接进入无需登录的第三方验真网页。PDF 模板和网页作为关联交付内容写在 TD3，不代表本次已授权实现网页或服务。
4. 主页采用定稿方案 E，按设计注释合入 E1：只留滑杆、金额可直接输入、存期柱按配置等分、用途横滑。B／C／D、E2–E5／E3b 等对比方案，以及高阳、Starling、Revolut 等参考素材不作为新增运行页面。
5. 动态姓名、金额、账号、利率、日期、存单号和验证码均为展示占位。示例起存额1,000美元、滑杆上限100,000美元、最高年利率4.50%等不是固定生产配置；未定参数就地标记，不从旧页面或实现推导。

## 描述口径

- 数值以正式 DTCG v1.2.0 为准，结构与业务状态按定稿；设计旧字号、档外尺寸及组件说明冲突在对应页标记，不自造 token。字体使用项目正式字体；设计可变字重510／590分别按 Medium／Semibold 描述，不将原始可变值当新字重 token。
- App 明暗主题使用同名语义色；本次所读主屏为深色，未独立核验的浅色、按下、错误和原型返回细节仍逐页待校准。PDF 是独立打印版式，不套 App 明暗主题或普通文字字号档。
- 未明确的返回清空、草稿时效、重启恢复与认证次数不继承 KYC／Payment 的业务规则。窗口或主题变化不应自动重提交易；其余生命周期在各页确认。
- 图中的外框强调色、方案标签、状态栏和 Home Indicator 示意不作为业务 UI。所有页面、半框与底栏处理实时安全区和键盘；支持310px窄窗口、宽窗口560px内容列、100%／200%字号，矮窗口半框最高90%。
