## 范围与流程关系

1. T1「Send to an EZB account」→ T2-00 输入账号／邮箱 → T2-01 金额 → T2-02 确认半框 → T2-03 验证 → T2-04 结果 → T2-05 交易详情。
2. T1「Send to another bank」→ T3-01 银行信息 → T3-02 收款人信息 → T3-03 金额与用途 → T3-06 复核 → 共用验证与异常结果 → T3-07 已提交 → T3-08 进度与退回。T3-04 是费用选择半框；T3-05 独立用途页已被金额页下拉取代，不是必经页。
3. T1 Payees／T4 联系人详情／交易详情 Send again／新增成功 Send money → 按联系人类型进入 T2-01 或 T3-03。进入时仍核对联系人有效性与信息变化，不把快捷入口当作验证豁免。
4. T1 See all → T4.1 联系人列表 → T4.4 详情；Add a payee → 类型半框 → T4.2 行内或 T4.3 海外新增 → PIN → 保存结果。单独新增和转账流程不同：前者明确保存，后者设计说明为转出成功后自动保存。
5. T4 以可见「FLOW T4 · 转账联系人」和 T4.1–T4.4 编号识别。外框历史名称不是另一项流程。
