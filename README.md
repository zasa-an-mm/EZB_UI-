## 阅读与维护

1. 先读颜色文档，再读 KYC 通用约定，最后逐 Flow 校准。
2. 颜色与共用规则只写一处；各页通过《文档名》互引，不复制外部工程路径、设计链接或过程记录。
3. UI 规格包含文本字号/字重/行高/颜色，容器背景/圆角/边距，相邻间距、图标资源名/尺寸/颜色及各交互状态。
4. 预估或不确定的参数、规则在发生位置标“（待校准）”；已明确的代码现值不伪装为新估值。
5. 契约直接保存在对应业务目录；校准状态用正文标记表达，不另设状态文件夹。当前 KYC 文档整体为初稿，校准结论原地修订，不靠后文覆盖前文。
6. 不在本库保存真实证件、账号、凭据、密钥或开发计划和任务进度。

7. 纯文本不设固定高度；图标、图片和控件可独立标注尺寸。明暗样式、操作状态、错误、焦点及大字号规则写在通用约定与各页正文中，不用外部资料或默认行为替代。
