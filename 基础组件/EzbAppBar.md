# EzbAppBar · 顶部导航栏契约

> **范围：**当前新设计系统顶部导航栏及其内置返回按钮、文字组和右侧文字操作。容器选择及滚动分工见 [EzbScaffold](EzbScaffold.md)，业务职责见 [基础页面](基础页面.md)，颜色字段见 [AppColor](../Color/AppColor.md)。尺寸为逻辑像素；行高按发布 token 原始单位标注，每项只保留一个值。

## §1 导航栏整体与阅读顺序

1. 栏背景 `bgBase`，无独立底部分隔线；顶部、左右避让设备安全区，不在本栏额外避让底部安全区。内容左右各16px；组件没有额外的顶部7px内边距。
2. 导航内容从左至右为可选前导控件、文字组、可选右侧文字操作；垂直方向按整行居中对齐。整行最小高44px，文字增高时整行增高，不能把44px当作所有内容的固定裁切高度。
3. 前导控件存在时占44×44px，其后到文字组12px；不存在时不预留按钮或这12px。文字组占剩余宽，即使不显示文字也保留中间弹性空间，将右侧操作推到行尾。
4. 右侧操作存在时，文字组与操作之间12px；不存在时不留这12px。栏内没有自动的开户步骤进度条、居中的业务大标题或页面说明卡。
5. 可选 `bottom` 放在整行下方，宽度填满栏内容横向范围、高度使用传入控件声明的高度，组件不额外插入间距。该控件不再自动套用主行的16px左右边距；需要边距时由该控件提供。

## §2 左侧返回或自定义控件

1. 非空 `leading` 优先，放入44×44px区域；即使 `automaticallyImplyLeading=false` 也显示该自定义控件。不再生成默认返回按钮；点击行为、标签和可用状态由自定义控件负责，`onBack` 不自动绑定到它。
2. 没有自定义前导控件时，仅当 `automaticallyImplyLeading=true`，且 `onBack` 非空或当前路由要求显示退出入口时，自动显示返回按钮。路由检查使用退出入口语义，不只是简单判断存在上一页；不自动改成抽屉菜单图标。
3. 默认返回按钮为 `EzbIconButton` 的 `glassSurface` 样式，圆形视觉与点击区域均44×44px。中心 `arrowLeft` 图形22×22px，描边1.65px，颜色 `iconPrimary`；图形与触控区独立，不通过放大箭头补足点击区域。
4. 正常底色 `bgNavGlass`；圆边使用1px高光，颜色由 `borderGlassEdge` 经过透明过渡到 `borderSubtle`。玻璃以局部背景模糊实现，当前渲染参数 sigma 为4；这是实现参数，不宣称等于设计工具的模糊半径。阴影水平0px、垂直4px、模糊12px、扩散−4px、黑色18%。
5. 按下或悬停时，在原底色上叠加 `bgSurfaceHover`，保留原来的圆形、模糊和尺寸，不出现默认水波纹；键盘聚焦时增加2px / `borderFocus` 的圆形焦点边框。
6. 默认自动返回按钮没有单独的“禁用返回”参数，生成后即具有回调。需要禁止离开时由业务返回逻辑和路由限制处理；不能只把右侧操作禁用后认为返回也被禁用。
7. 默认按钮在高对比度环境下降级为 `bgSurface2` 实底，不绘制玻璃材质与相应阴影；导航栏本身没有暴露“减少透明度”开关，需要该配置时通过自定义 `leading` 提供对应按钮。不要把按钮组件支持某配置等同于导航栏已经自动传入该配置。
8. 点击时优先执行 `onBack`，没有时调用 `Navigator.maybePop`。用途标签优先 `backSemanticLabel`，否则采用系统本地化返回提示；返回箭头默认随从右到左文字方向镜像。系统返回与资料保存不由这个回调自动统一，见《基础页面.md》§4。

## §3 中间标题与副标题

1. `title` 为null或空字符串时不显示标题；有文字时上方标题13px / w400 / 行高18px / 字距0px / `textPrimary`，字体 token 为 SF Pro，内容区域横向展开。标题带标题语义，不固定文字高度，也不指定单行省略。
2. `subtitle` 为null或空字符串时不显示副标题；有文字时为11px / w500 / 行高15px / 字距0px / `textTertiary`，字体同上。只有标题和副标题都存在时，两者之间增加1px；只有副标题时不留空标题行。
3. 文字组按起始侧排列，不强制居中。长文、系统动态字号和本地化内容参与高度计算，允许换行；开启系统粗体时，文字组与右侧操作的字重提升为粗体。
4. 标题、副标题没有直接暴露样式覆盖参数。KYC 的28px大标题由业务页面在正文提供，标准导航栏仅显示操作；不能把 `title` 参数当成任意字号的页面主标题。本轮不修改或扩展本组件。
5. 同一个内置标题组被 `EzbScaffold` 移到滚动正文时仍使用上述规格，不自动变成大标题。页面不要同时传入同样的便捷标题、又在正文重复绘制一次。

## §4 右侧文字操作

1. `action` 为空时不显示；非空时提供一个 `EzbAppBarAction`，必需内容为 `label` 和可空的 `onPressed`，可选 `semanticLabel` 与 `focusNode`。文案由页面本地化，例如Done或Cancel，不由导航栏固定。
2. 文字13px / w500 / 行高18px / 字距0px，正常 `textSecondary`，禁用 `textDisabled`；字体 SF Pro。右对齐到操作区域行尾，操作区再与导航内容右边界对齐，不使用主按钮的品牌底色。
3. 操作区域优先容纳实际文字宽度及44px最小触控宽度，同时受可用空间上限约束。上限为扣除前导控件后可用宽度再减12px的一半；极窄宽度下可能小于44px，当前实现不保证在任意宽度同时满足左右内容与44px宽触控，适用最小屏宽和补救方式。
4. 点击区最小高44px，文字可换行撑高。无填充、无额外内边距、无水波纹；正常不绘制边框，聚焦时绘制2px / `borderFocus` 焦点边框、圆角8px。键盘焦点与按钮语义由内部透明操作组件处理。
5. `onPressed=null` 时禁用，不能触发操作；有回调时只执行页面回调，不自动提交表单或关闭页面。`semanticLabel` 非空时作为外层用途标签并排除内部重复文字语义；为空时由可见文字提供标签。
6. 默认栏只提供一个右侧文字操作，不直接提供多个图标操作列表。需要其他结构时使用自定义导航栏，并明确新结构的契约。

## §5 高度、系统栏与使用方式

1. `preferredSize` 提供的最小栏高为44px加 `bottom` 声明高度，不包含顶部状态栏。实际布局需按宽度、文字、系统字号计算；普通页面优先交给 `EzbScaffold` 处理。
2. `preferredSizeFor` 计算时，从整栏宽度扣除左右安全区、两侧16px边距、存在的44px前导区域及12px间距，再为右侧操作分配宽度；用剩余宽度测量标题与副标题的总高，与右侧文字高、44px最小高比较取最大，再加 `bottom` 高度。
3. 配合 `EzbScaffold` 时，容器对极长栏内容限制占用高度，栏内部可纵向滚动。单独用于普通 `Scaffold` 时，调用方应按实际宽度取得高度并配置 `PreferredSize`；只使用最小 `preferredSize` 不能保证大字号或长文完整呈现。
4. 本栏默认状态栏透明，状态栏图标明暗随当前主题；局部 `systemOverlayStyle` 非空时覆盖本栏默认配置。页面背景覆盖不自动覆盖本栏底色，也不自动改变该局部系统栏配置。
5. 当前参数没有顶部外边距、返回区到正文距离、大标题字号或导航栏背景色的直接覆盖入口。KYC 标准返回导航与正文标题间的14px由业务页面在正文顶部实现，不修改导航栏，不逐页复制返回按钮；顶部留白仍按业务页规则提供。
6. 返回按钮和右侧操作固定还是随页面滚动，由容器组合决定；`EzbScaffold.scrollable=true` 仅让文字标题组进入正文，导航操作仍固定。正文到栏的业务留白不在本栏中自动追加。
