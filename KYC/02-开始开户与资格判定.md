# Flow 02 · 开始开户与资格判定 UI 和交互说明

> **范围：**居住国选择页10、定位说明10a、其他国家展开态10b/10d、国家选择器10c-b、不支持国家10e及巴林居民10f。封面、说明卡和历史对比稿不属于 App 页面。
>
> 颜色随当前明暗主题取《../Color/AppColor.md》对应字段，亮色表现（待校准）。px 为逻辑像素；文字高度随内容撑开，预估项标“（待校准）”。

### §1 居住国选择页（10，含10b/10d）

1. **入口与页面底：**从开户入口进入，已有登录态但尚未开户用户也进入同一流程。全页背景 `bgBase`，内容左右各16px；顶部安全区随设备，正文与固定底部动作区分开，小屏可纵向滚动。初次进入不把推荐国家当作用户已经确认的居住国。 支持200%字号，正文可滚动，底部操作不遮挡字段。
2. **左上返回键：**复用 `EzbScaffold` + `EzbAppBar`。点击与系统返回执行同一动作：返回进入本页前的页面，保留本次居住国草稿（待校准）；是否弹出退出确认框（待校准）。
3. **标题：**返回键点击区域底缘向下14px为正文标题，间距由本页提供；标题为“Where do you live?”，左对齐；28px / w700 / 行高33px / `textPrimary`。宽度填满内容区，不设文字定高，换行时其下内容顺延。
4. **标题下说明：**标题文字底缘到说明顶缘8px；文案“Please select your country of permanent residence.”，15px / w400 / 行高20px / `textSecondary`，左对齐。此处询问永久居住国，不是国籍、手机号所属国或护照签发国。
5. **推荐国家行：**说明底缘到本行顶缘24px。容器铺满内容宽，底 `bgSurface2`，圆角16px，内边距16px，常规最小高77px，长文自撑；内部从左至右为定位图标、文字组、单选圈，垂直居中。
   > 左 `mapPin` 图标22×22px / `iconSecondary`；图标右缘到文字组左缘14px。文字组占剩余空间，上为推荐国家名，17px / w500 / 行高23px / `textPrimary`；下为“From your mobile number”，15px / w400 / 行高20px / `textTertiary`（待校准），两行间2px。推荐来自定位时是否替换来源说明（待校准）。示例 Singapore 不是固定值。
   > 文字组右缘到单选圈至少14px；圈22×22px，未选底 `bgControlOff`，右缘距容器右缘16px。整行和选择圈均可选择，选中后行底改 `bgBrandSelected`（待校准），圈底 `iconBrand`、内部 `check`14×14px / `iconOnBrand`（待校准），不加选中描边。
   > 点击推荐行即确认该推荐国；取消“其他国家”选中并收起其字段，但保留其他国家的草稿值（待校准）。再次点击已选行不取消（待校准）。无推荐值时隐藏该行、直接显示手动国家字段（待校准）；定位/区号推荐优先级仍待校准。
6. **其他国家行：**推荐行底缘到本行顶缘12px；容器、文字组及选择圈位置同上一行，左图标换 `globe`22×22px / `iconSecondary`。主文“Somewhere else”，17px / w500 / 行高23px / `textPrimary`；副文“Pick from the full list”，15px / w400 / 行高20px / `textTertiary`（待校准），间2px。
   > 点击整行或单选圈，选中该行并取消推荐项；在本行下方展开国家字段。选择圈及底面选中样式同上一行，不跳转新页面。
7. **国家选择框：**选择“Somewhere else”后，在该选项下方显示。
   > **容器：**距“Somewhere else”卡片底缘16px（待校准），横向填满内容区；背景 `bgSurface2`，圆角16px，无边框；内边距左右16px、上下14px，最小高71px。
   > **左上标签：**“Country of residence”，13px / w400 / 行高18px / `textSecondary`，左对齐。
   > **标签下方文字：**距标签底缘2px；未选择时显示“Select your country”，选好后替换为国家名称，均为17px / w400 / 行高23px / `textPrimary`，左对齐。
   > **右侧箭头：**`chevronDown`，20×20px / `iconPrimary`；距容器右缘16px，与左侧文字组垂直居中，距文字至少8px（待校准）。
   > **点击：**点击整个选择框，打开本文件§3的国家选择器；确认国家后，将国家名称显示在标签下方。
8. **底部 Continue：**动作区铺满屏宽，底 `bgBase`，左右16px、顶部16px、底部为设备安全区+8px。按钮铺满内宽、最小高56px、圆角28px，文案“Continue”，17px / w600 / 行高23px、居中。
   > 未确认推荐国，或选其他国家但字段无值时禁用，底 `bgDisabled`、字 `textDisabled`。有完整居住国后可用，底 `brandPrimary`、字 `textOnBrand`。本页末项到动作区至少16px（待校准），滚动到底时字段不被按钮覆盖。
   > 点击后发起资格判断，按钮阻止重复点击并显示处理中反馈（待校准）；可服务国家进入《03-证件与人脸.md》§1，普通不支持国家进入本文件§4，巴林居民进入§5（待校准）。失败原地保留选择，在按钮上方8px显示13px / w400 / 行高18px / `feedbackError`提示，允许重试（待校准）。

### §2 定位用途说明弹层（10a）

1. **出现位置：**覆盖在§1页面上，底部升起；第一次进入且未决定定位权限时展示（待校准）。背景页不接收点击，遮罩 `bgOverlayScrim`；定位仅用于推荐国家，用户仍须确认。
2. **弹层容器与抓手：**宽为屏宽，底 `bgElevated`，顶角26px，左右内边距16px，底部设备安全区另计。顶部居中抓手36×5px、圆角3px、`bgTrack`，距顶5px；抓手底到图标53px（待校准）。 阴影水平0px、垂直−10px、模糊28px、扩散−8px、黑色32%。
3. **定位图标：**`mapPin`64×64px / `iconBrand`，水平居中。图标底缘到标题14px（待校准）。
4. **标题与说明：**标题“Use your location?”，20px / w600 / 行高27px / `textPrimary`，居中；标题底到说明8px。说明“Only to pre-select your country of residence — you can also pick it yourself. We don’t track where you go.”，15px / w400 / 行高20px / `textSecondary`，居中换行，不定高。
5. **允许按钮：**说明底到按钮22px（待校准）；“Allow while using the app”，最小高56px、圆角28px、底 `brandPrimary`、字17px / w600 / 行高23px / `textOnBrand`。点击关闭软说明并请求系统定位授权（待校准）；系统框使用平台原生样式。
6. **Not now：**主按钮底到本操作12px（待校准），文字15px / w500 / 行高20px / `textBrand`、居中，透明点击区最小44px高。点击关闭弹层、回到国家选择页，不再次立即询问；拒绝系统授权也仍允许手动选国（待校准）。遮罩/下滑/系统返回同Not now处理（待校准）。

### §3 国家选择器（10c-b，暂按 Done 备选，整体待校准）

1. **容器：**由国家字段打开，保持承载页选择；底部弹层最大高为可用屏高85%（待校准），背景 `bgElevated`、顶角26px、左右16px、遮罩 `bgOverlayScrim`。仅中部列表滚动，标题固定；键盘弹出后列表收缩，不遮住Done（待校准）。 阴影水平0px、垂直−10px、模糊28px、扩散−8px、黑色32%。 支持200%字号，正文可滚动，底部操作不遮挡字段。
2. **抓手与标题行：**抓手36×5px / `bgTrack`、圆角3px、顶距5px；抓手底到标题行20px（待校准）。标题行左侧“Country of residence”，17px / w600 / 行高23px / `textPrimary`；右侧“Done”，15px / w600 / 行高20px / `textBrand`，点击区44×44px，右缘与内容区右缘对齐（待校准）。
   > 没有临时选中时Done禁用、字色 `textDisabled`；有选中时点击才写回§1字段并关闭弹层。点行不立即提交；点遮罩、下滑、系统返回关闭弹层并回滚本轮临时选择（待校准）。
3. **搜索框：**标题行底缘向下16px（待校准）；最小高44px、圆角16px、底 `bgField`、左右内边距12px。左 `search`20×20px / `iconSecondary`，到中间文字8px；输入占余宽，15px / w400 / 行高20px / `textPrimary`，空占位“Search 200+ countries”用 `textTertiary`；非空时右侧 `circleX`20×20px / `iconTertiary`，点击区44×44px且不挤压输入（待校准）。清除只清搜索，不清已选国家。
4. **国家列表：**搜索框底到首行16px（待校准）；按国家显示名排序（待校准），每行铺满、最小高56px、左右16px/上下12px、圆角16px，行间8px（待校准）。左国名17px / w400 / 行高23px / `textPrimary`；右22×22px选择圈，文字到圈至少14px。未选圈 `bgControlOff`，选中圈 `iconBrand`、勾14px/`iconOnBrand`；选中行底 `bgBrandSelected`，未选行底 `bgSurface2`（待校准）。点击整行仅切换本弹层临时选中，不多选。
5. **搜索无结果：**输入即过滤，按显示名与常见名不区分大小写匹配（待校准）；列表空时距列表区顶24px显示“No matching countries”，15px / w400 / 行高20px / `textSecondary`，居中（待校准）。清空恢复全集；“200+”只是占位文案，不固定实际国家数量。

### §4 不在服务范围页（10e）

1. **页面底与起点：**全页 `bgBase`，正文左右16px，水平居中；主体起点距顶部安全区底缘170px（待校准），不显示额外返回入口（待校准）。小屏或字号放大时正文可滚动，底部操作独立保留。
2. **状态图形：**圆底104×104px / `feedbackWarningBg`，内 `circleMinus`54×54px / `feedbackWarning`、居中（待校准）；图形底到标题26px。
3. **标题：**“EZB isn’t available in your country yet”，28px / w700 / 行高33px / `textPrimary`，居中自然换行；底到说明12px。
4. **说明：**“We can’t open accounts for residents of this country yet. We’ll email you if that changes.”，15px / w400 / 行高20px / `textSecondary`，居中；此处停止继续收集开户资料。邮件通知承诺及订阅依据（待校准），不表示页面已经代用户完成订阅。
5. **Go to home：**固定底部操作区铺满屏宽，底 `bgBase`，左右16px、顶部16px、底部为设备安全区+8px；主按钮铺满区内宽，最小高56px、圆角28px、左右内边距16px，文字17px / w600 / 行高23px、居中，正常底 `brandPrimary` / 字 `textOnBrand`，禁用底 `bgDisabled` / 字 `textDisabled`；文字换行可增高，禁用不可点击，处理中阻止重复触发；点击返回当前登录用户首页并结束当前资格页（待校准），不进入护照步骤。系统返回是否同此出口（待校准）。

### §5 巴林居民页（10f）

1. **页面底、主体与状态图形：**底 `bgBase`、左右16px，主体起点距顶部安全区底缘170px（待校准），小屏可滚动；警示圆104×104px / `feedbackWarningBg`，内 `circleMinus`54×54px / `feedbackWarning`、居中（待校准），不与普通不支持国家共用业务判定；巴林居民规则为只建客户号、不开银行账户。
2. **标题：**图形底缘向下26px为“Accounts aren’t available to Bahrain residents”，28px / w700 / 行高33px / `textPrimary`，居中换行。
3. **说明：**距标题12px；“As a Bahrain resident, you can’t open an EZB account in the app. The Help Centre explains what’s available.”，15px / w400 / 行高20px / `textSecondary`，居中。页面不得显示账户已开或可入金的成功信息。
4. **底部主操作：**“Go to home”，固定底部操作区铺满屏宽，底 `bgBase`，左右16px、顶部16px、底部为设备安全区+8px；主按钮铺满区内宽，最小高56px、圆角28px、左右内边距16px，文字17px / w600 / 行高23px、居中，正常底 `brandPrimary` / 字 `textOnBrand`，禁用底 `bgDisabled` / 字 `textDisabled`；文字换行可增高，禁用不可点击，处理中阻止重复触发。暂在客户号创建成功后展示本页，点击进入客户号已建立但无账户的首页（待校准）；创建失败的提示与重试仍待校准，不把创建失败展示成本页成功。
5. **帮助中心：**主按钮下12px（待校准）为“Open Help Centre”，17px / w600 / 行高23px / `textBrand`、无实底，44px高点击区；点击打开巴林居民适用服务说明，关闭后回本页（待校准）。最终返回目标、客户号创建时机及无账户首页可用功能（待校准）。
