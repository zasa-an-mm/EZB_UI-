# KYC 通用样式与交互约定

> **范围：**Flow 02–05 的共用页面与控件。颜色见《Color/AppColor.md》；各 Flow 描述自己的内容、状态和跳转。
>
> **校准标记：**“（待校准）”紧跟尚未确定的数值或规则；同一条款内标记应紧跟待确认参数，不将整页笼统标记代替局部标记。未标记的颜色为代码现值，尺寸为已有基础规格或本次读取值，仍属于待用户审阅的契约初稿，不假称已人工验收。

## §1 单位、排版与布局

1. px 均为逻辑像素。402×874 是阅读基准，不是运行设备的固定大小；横向内容宽 = 可用屏宽 − 32，基准宽 370。
2. 页面左右外边距 16px。纯文本不定高；以字号、字重、行高撑开，相邻距离均从可见边界起量。
3. 普通内容随可用空间纵向布局；长表单、键盘展开与 200% 字号下允许滚动。底部动作区保持可操作，不盖住最后一项；内容末尾额外预留 16px（待校准）。
4. 已读画面普遍深色；亮色使用《AppColor.md》的亮色列，亮色页面整体呈现（待校准）。不以暗色吸色替代语义字段。

| 用途 | 字号 / 字重 / 行高 | 颜色 |
| --- | --- | --- |
| 页面标题 | 28px / w700 / 33px（约 118%） | `textPrimary` |
| 分组标题 | 17px / w500 / 23px（约 135%） | `textPrimary` |
| 小分组标签 | 13px / w500 / 18px（约 138%） | `textTertiary` |
| 主正文 / 字段值 | 17px / w400 / 23px（约 135%） | `textPrimary` |
| 说明 | 15px / w400 / 20px（约 133%） | `textSecondary` |

| 主操作 | 17px / w600 / 23px | 主按钮 `textOnBrand`；次操作 `textBrand` |

正文使用系统字体；数字不额外替换字体。图形不随字号放大，文字容器随内容增长。

## §2 顶部返回与页面起点

1. 顶部安全区由设备提供，不绘制设计中的时间、刘海和电量。标准页返回键点击区 44×44，左外边距 16，点击区顶缘距顶部安全区底缘 7px（待校准）。
2. 返回图标 `arrowLeft`，22×22，`iconPrimary`；圆形底 `bgNavGlass`，半径 22。图标居中；独立描边宽 1.65（现有玻璃按钮规格）。
3. 返回区底缘到标题顶缘 11px（待校准），使基准画面标题约在页面 y=116。实际布局按安全区与上述间距，不锁死 y 坐标。
4. 普通标题左对齐；结果页、PIN 和身份核验完成页按各页居中。标题到说明 8px，说明到底下第一组内容通常 24px；页面另有明确标注时按页面条款。
5. 系统返回与可见返回键执行同一业务目标（待校准）；退出申请的确认规则集中在校准清单 Q01/Q03。

## §3 字段与选择字段

1. 默认横向铺满内容区；圆角 16；底 `bgField`；常规最小高 71，有辅助文字最小高 91。长标签、地址与大字号可继续增高。
2. **当前组件内边距**：左右16、上下12；标签到值4、值到辅助4。页面图层另出现上下14、内部间距2以及底 `bgSurface2`，本契约暂沿用当前组件值，差异（待校准）。
3. 标签13/w400/18/`textSecondary`；值17/w400/23/`textPrimary`；空占位使用17px / w400 / 行高23px / `textTertiary`。只读值与输入值采用同一排版。
4. 当前常规边框1px/`borderControl`；聚焦边框2px/`borderFocus`，标签转 `textBrand`；错误底 `bgErrorTint`，标签/辅助 `feedbackError`，不另加错误边框。是否移除常规边框以匹配页面无边框形态（待校准）。
5. 禁用底 `bgDisabled`，文字 `textDisabled`，不响应输入；只读不等于禁用，护照核对字段保持正常可读对比度。
6. 选择字段右侧 `chevronDown`，20×20，`iconSecondary`，距右边16、与值至少8px（待校准）；不盖住长文字。整字段可点击，点击打开对应选择列表。
7. 字段之间12px；必填提示置于字段下方，不挤占输入行。错误文案13/w400/18，距值4px；多行自撑。

## §4 单选行与 Chip

### §4.1 单选行

1. 容器内边距16、圆角16、宽度填满；主文17/w500/23/`textPrimary`，副文15/w400/20/`textSecondary`，主副间距2px。
2. 左图标22×22，`iconSecondary`；图标到文字14px。右选择圈22×22，距文字最少14px；文字占余宽。无图标的行不保留左图标空位（待校准）。
3. 未选底 `bgSurface2`、圈底 `bgControlOff`；选中底暂按 `bgBrandSelected`（待校准），圈底 `iconBrand`，内勾 `check` 14×14/`iconOnBrand`（待校准）；整行无描边。
4. 只有标题时最小高55px（待校准）；有副文时最小高77px；长文或大字号向下增长。选项间距12px，整行单选、再次点击已选项不取消（待校准）。

### §4.2 Chip

1. 左右内边距16、上下11；文字15/w500/20，圆角为高度一半。视觉高42，点击区至少44，不用扩大布局行高制造假间距。
2. 行内横向间距8、换行间距8，按内容自然换行，不拉成等宽按钮。
3. 未选底 `bgSurfaceRaised`、字 `textPrimary`；选中底暂按 `brandPrimary`、字 `textOnBrand`（待校准）。组件说明中的浅品牌底方案与页面实色方案需校准，不自行合并。
4. 就业类别单选；用途与资金来源多选，可取消已选；选中上限和至少一项规则见对应页面。

## §5 卡片、信息行与提醒

1. 信息卡底 `bgGlass`、圆角20、左右内边距16、上下16；内容行最小高64，按上下14内边距自撑，行间不另加描边。部分旧图层有72高及分隔线，沿用既定64与无分隔线口径。
2. 提醒卡底 `bgGlass`、圆角16、内边距16；左图标20×20/`iconSecondary`，到文字12px。标题15/w600/20/`textPrimary`，正文15/w400/20/`textSecondary`，标题到正文4px（待校准）。
3. 信息行标签13/w400/18/`textSecondary`，值17/w500/23/`textPrimary`，标签值间2px；可跳转分组右侧 `chevronRight`20×20/`iconSecondary`。文本长时换行，箭头不挤到文本内。
4. 玻璃视觉模糊13，降低透明度时使用 `bgSurface2` 实色，不改变版式；渲染引擎的模糊参数不作为额外设计数值。

## §6 底部动作区

1. 宽度填满屏幕，左右16、顶部16；底部 = 设备安全区 + 8px。纯色页面底 `bgBase`；渐变页动作区过渡方式（待校准）。
2. 主按钮最小高56、圆角28，宽度填满；文字17/w600/23居中，横向16。多行文字可增高；按钮说明中的52/26不覆盖现有56/28。
3. 主底 `brandPrimary`、字 `textOnBrand`；禁用底 `bgDisabled`、字 `textDisabled`。按下压暗、加载菊花与点击反馈（待校准）。
4. 次按钮与主按钮间12px（待校准）；文字型次操作无实底、字 `textBrand`，点击区至少44高。次操作不是与主按钮同一回调。
5. 禁用时不可点击；处理中阻止重复提交并保持文案宽度（待校准）。不把按钮变亮当作业务已经完成。

## §7 半弹层

1. 底 `bgElevated`、顶圆角26，左右内容边距16，底部安全区另计；遮罩 `bgOverlayScrim`。
2. 抓手36×5、圆角3/`bgTrack`，顶距5；抓手底到普通弹层内容首项53px为现有标准。内容选择器/长文档可按具体页另定，不把此距离机械套给所有弹层。
3. 标题20/w600/27/`textPrimary`；说明15/w400/20/`textSecondary`，标题到说明8px；内容到动作22px（待校准），普通动作弹层。
4. 现有阴影：水平0、垂直−10、模糊28、扩散−8，黑32%。普通系统授权框不使用本样式。
5. 点遮罩、下滑、系统返回关闭与是否回滚选择（待校准）；具体页面必须写明，不用“组件默认”代替业务规则。

## §9 共用交互与校准

1. 页面返回目标按各 Flow；修改已填内容后返回时保留本组草稿（待校准）。改变上游资格或护照后，下游失效范围（待校准）。
2. 输入错误就近显示在字段下方；点击 Continue 校验当前页，滚动并聚焦第一个错误（待校准）。加载失败保留输入，提示13/w400/18/`feedbackError`，附44高重试操作（待校准）。
3. 页面契约以实际画面为章节，在章节内按从上到下、行内从左到右逐项描述；同一元素的尺寸、文案、样式、状态和点击结果写在同一条款。不再另设UI标注、页面结构、选择状态等分类章节。所有不确定行为在发生位置标（待校准），校准清单仅作导航。
4. 本库不依赖外部设计链接、截图或工程文件才能理解规则；未能确认的参数给出候选并标（待校准），不以外部资料代替具体执行条款。

## §10 可访问性与隐私共用要求

1. 支持至少200%动态字号、44×44触控区、合理焦点顺序、读屏标签与状态播报；相关布局规则见§1、§8、§9。
2. 普通文字对比度至少4.5:1、大字至少3:1，非文本部件至少3:1；图片、实时相机和渐变上的内容单独核对。
3. 敏感凭证、身份和账户资料按实际屏上内容分级保护；交易 PIN 使用应用内键盘，不写入普通草稿或日志。
4. 减少动态效果与减少透明度时，保持内容和操作完整；玻璃降级遵循§5，不改变版式。
