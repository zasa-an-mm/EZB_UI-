## 文案与申请恢复

- 页面标题、辅助说明、按钮等文案支持管理端配置。默认跟随系统语言；没有对应语言配置时使用英文。
- 重新进入开户时先查询后台开户与申请状态；有有效申请时恢复对应页面，已有最终结果时按结果页的保留规则展示，不重复创建在途申请。
- 未到终态的申请检查保存时效：整个申请的有效期必须配置，当前节点可单独配置停留时效。任一有效期超限，申请关闭，回到未开户且无在途申请的状态；未配置节点时效时，仅检查整个申请有效期。不追溯已完成节点的停留时间。

## 校准方式

- 可以直接指出参数，例如“Flow 03，芯片页，插画宽改成320”。
- 参数被确认后原地改值并移除该项“（待校准）”，其他未确认项继续保留。
- 颜色数值按 AppColor.md 的代码现值；若要改变语义或色值需明确指明，不能因视觉校准误改历史色。
- 当前没有正式生效的逐屏契约；本组不维护开发计划、任务或验收进度。
