## 校准方式

- 可以直接指出参数，例如“Flow 03，芯片页，插画宽改成320”。
- 参数被确认后原地改值并移除该项“（待校准）”，其他未确认项继续保留。
- 颜色数值按 AppColor.md 的代码现值；若要改变语义或色值需明确指明，不能因视觉校准误改历史色。
- 当前没有正式生效的逐屏契约；本组不维护开发计划、任务或验收进度。
