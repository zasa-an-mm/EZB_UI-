# Flow 04 · 关于你 UI 和交互说明

> **范围：**就业页17及自雇31/无业17b、用途与资金来源19、住址与证明21/21b、税务居民22及无TIN32/其他原因32b/多组22c。
>
> **通用规格：**颜色见《Color/AppColor.md》；页面壳见《00-通用约定.md》§1–§2，字段见§3，选项见§4，底部动作区见§6。字段都在发生位置描述其编辑与条件状态，以下均为待用户校准的初稿。

### §1 工作与收入页（17，含31/17b）

1. **页面与返回：**从身份核验完成页进入，底 `bgBase`，内容左右16px、长表单可滚动；左上返回按通用§2，返回身份核验完成页并保留本页草稿（待校准）。从提交前复核进入编辑时，返回目标改为复核页（待校准）。导航复用 `EzbScaffold` + `EzbAppBar`，安全区下方留7px。
2. **标题：**正文标题顶缘距返回按钮点击区域底缘14px；“Your work”，28px / w700 / 行高33px / `textPrimary`、左对齐；标题底向下24px开始就业类型选项。
3. **就业类型行：**从左至右为“Employed”“Self-employed”“Not employed”，单选。每枚Chip文字15px / w500 / 行高20px、左右内边距16px/上下11px、视觉高42px、圆角为高度一半，点击区至少44px高；横向和换行间距均8px，按内容自然换行，不拉成三等分。
   > 未选底 `bgSurfaceRaised`、字 `textPrimary`；选中底 `brandPrimary`、字 `textOnBrand`（待校准）。初始不预选（待校准），选定后原地出现对应字段组。点击不同类型只替换下方组，不清空其他类型暂存草稿；提交仅使用当前类型的数据（待校准）。
4. **字段组标签：**Chip组底下24px为“Employer details”/“Business details”/“Your situation”，依当前类型替换；13px / w500 / 行高18px / `textTertiary`，左对齐，底到首字段12px。
5. **受雇时的 Industry：**组内第一项，铺满内容区、圆角16px、底 `bgField`、左右16px/上下12px、最小高71px；标签“Industry”13px / w400 / 行高18px / `textSecondary`；下4px值17px / w400 / 行高23px / `textPrimary`，空时占位用 `textTertiary`。右 `chevronDown`20×20px / `iconSecondary`，右距16px、距文字至少8px（待校准）；点击整项打开行业选项，确认后原地写回（待校准）。
6. **受雇时的 Occupation：**Industry底下12px；同字段排版，标签“Occupation”。暂按自由文本、无下拉图标（待校准）；若改为字典选择需校准后同步形态，不因示例“Designer”推定唯一选项。
7. **受雇时的 Employer name：**前字段下12px，标签“Employer name”，值为可输入雇主名称；沿用前述字段尺寸和颜色，不使用示例公司作为默认值。长文本和字数上限（待校准）。
8. **受雇时的 Employer registered address：**前字段下12px，标签同名，自由输入注册地址；值17px / w400 / 行高23px / `textPrimary`，允许换行自撑，不强制单行或截断，字段仍左右16px/上下12px。
9. **受雇时的 Annual income：**前字段下12px，标签“Annual income”，右侧选择箭头与Industry相同；选择年收入区间，不手填精确收入。区间显示17px / w400 / 行高23px，示例“US$50,000 – 80,000”仅为展示例子，完整区间名单（待校准）。
10. **切换自雇（31）：**字段组在相同位置改为Business details，自上而下为“Nature of business”“Trading name”“Industry”“Country of operation”“Annual income”，项间12px，所有标签/值/容器样式与上文相同。
    > 前两项分别输入业务性质和经营名称、无尾随箭头（待校准）；Industry、Country of operation及Annual income为选择字段。经营国家不自动等于居住国（待校准）。不同时保留受雇字段的视觉空位，不将隐藏的雇主资料作为自雇必填项。
11. **切换无业（17b）：**字段组在相同位置改为Your situation；依次“Current status”“Main source of income”“Annual income”，项间12px。前两项暂按选择字段，收入字段仍选择区间（待校准）；每项文字、右箭头及点击区与Industry相同。画面包含年收入而批注只提状态和收入来源，当前候选保留年收入（待校准），不能当成已确认删去或保留。
12. **Continue：**底部动作区按通用§6，56px高、圆角28px、17px / w600 / 行高23px。未选择类型或当前显示的必需字段不完整时禁用、底 `bgDisabled`/字 `textDisabled`；填写有效后底 `brandPrimary`/字 `textOnBrand`（待校准）。初步按当前分组所有项必填（待校准）；点击校验当前组，错误就近显示，保留输入。
    > 正常路径进入§2；从复核编辑进入时确认后直接回复核，不重走后续组（待校准）。行业、职业等选择器暂按《02-开始开户与资格判定.md》§3的搜索和Done确认交互；选项全集、必填、长度规则为Q11待校准项。

### §2 用途、资金来源与活动档位页（19）

1. **页面与标题：**底 `bgBase`、左右16px，返回键返回§1且保留本页选择（待校准）；正文标题顶缘距返回按钮点击区域底缘14px；标题“How will you use it?”，28px / w700 / 行高33px / `textPrimary`，左对齐。导航复用 `EzbScaffold` + `EzbAppBar`，安全区下方留7px。
2. **用途标题：**页面标题底下24px为“Main purpose (select all that apply)”，17px / w500 / 行高23px / `textPrimary`；标题下12px为用途Chip组。
3. **用途Chip组：**从左至右、满行换行，顺序“Savings”“Investment”“Everyday payments”“Crypto on/off ramp”；尺寸、8px横纵间距及选中/未选颜色沿用§1第3条。每枚可独立多选，点击已选项取消，不固定设计示例的选中值。
4. **资金来源标题：**用途组最末行底缘向下24px为“Source of funds (select all that apply)”，17px / w500 / 行高23px / `textPrimary`；下12px开始多选Chip。
5. **资金来源Chip组：**依次“Salary”“Business income”“Pension / social security”“Rental income”“Investment income”“Inheritance”；从左至右排满再换行，样式与上组相同，操作互不影响用途组。选项是否扩展、最多选择数（待校准）。
6. **活动档位标题：**资金来源组底下24px为“How much do you expect to move each month?”，17px / w500 / 行高23px / `textPrimary`，允许两行；标题底下12px开始第一条档位行。
7. **Low 行：**底 `bgSurface2`、圆角16px、内边距16px、最小高77px，内部左文字组占余宽，右选择圈22×22px，圈右距16px、距文字至少14px。主文“Low”，17px / w500 / 行高23px / `textPrimary`；下2px副文“Under 10 payments · under US$10k in total”，15px / w400 / 行高20px / `textSecondary`。无左图标，不留空白占位（待校准）。
8. **Medium 行：**前行底下12px，同布局；主文“Medium”，副文“10–50 payments · US$10k – 50k in total”。
9. **High 行：**前行底下12px，同布局；主文“High”，副文“Over 50 payments · over US$50k in total”。三行互斥选择，未选圈 `bgControlOff`；选中行底 `bgBrandSelected`、圈 `iconBrand`、勾14px/`iconOnBrand`（待校准），不加描边。再次点击已选行不取消（待校准）。金额与笔数跨档时如何归档、区间边界仍待校准；不另加精确数字输入框。
10. **Continue：**按通用§6固定底部，内容区可滚动并露出High行；用途与资金来源各至少一项、活动档位恰有一项才可用（待校准），否则禁用。正常进入§3，复核编辑回复核页（待校准）；返回不清空选择，不默认替用户选中示例档位。

### §3 住址与地址证明页（21，含21b）

1. **页面与标题：**底 `bgBase`、左右16px，返回§2并保留地址与已上传文件（待校准）。正文标题顶缘距返回按钮点击区域底缘14px；标题“Your home address”，28px / w700 / 行高33px / `textPrimary`、左对齐；下8px说明“Where you actually live. We’ll ask for one document that shows it.”，15px / w400 / 行高20px / `textSecondary`。导航复用 `EzbScaffold` + `EzbAppBar`，安全区下方留7px。
2. **Street address：**说明底下24px。字段规格同§1第5条，标签“Street address”；输入实际街道/门牌/房号，不作示例默认值；值可多行，字段自然增高，不裁切。地址与文档匹配规则（待校准）。
3. **City：**前字段底下12px，标签“City”，同普通输入字段，无尾随箭头（待校准）；不根据地址字符串擅自补城市。
4. **Postal code (optional)：**前字段下12px，同字段规格；可留空，留空不阻断本页继续；各国邮编格式、键盘类型（待校准）。
5. **Country：**前字段下12px，同选择字段，右 `chevronDown`20px / `iconSecondary`；暂预填已确认居住国且允许修改（待校准），修改后与资格国不一致时如何处理（待校准）。不能悄悄以护照国籍覆盖本值。
6. **Proof of address 标签：**国家字段底下24px，“Proof of address”，13px / w500 / 行高18px / `textTertiary`；下12px为首个上传入口。
7. **Take a photo：**操作行填满内容宽，底 `bgSurface2`、圆角16px、左右16px/上下12px、最小高44px（待校准）；左 `camera`20×20px / `iconSecondary`，到文案12px，文案“Take a photo”，15px / w500 / 行高20px / `textPrimary`。整行点击打开相机，首次使用前解释证明文件用途（待校准）；取消回本页不清地址。
8. **Choose from photo library：**前行下12px，同操作行；左图库图标资源名（待校准）、20×20px / `iconSecondary`，右文案“Choose from photo library”；点击系统相册，仅选择一份证明（待校准），取消保持原状态。
9. **Choose a file：**前行下12px，同操作行；左 `fileText`20×20px / `iconSecondary`，文案“Choose a file”；点击文件选择器，允许PDF/JPG/PNG，单份最大10MB。MB换算、页数与压缩规则（待校准），格式或超限错误不能显示为上传成功。
10. **格式与已上传状态：**未上传时，最后操作行下12px显示“PDF, JPG or PNG · up to 10 MB”，13px / w400 / 行高18px / `textTertiary`。
    > 上传中与上传成功后，在原上传区域用文件行呈现，不另开一页（待校准）；行最小高64px、底 `bgSurface2`、圆角16px、内边距16px。左 `fileText`24px/`iconSecondary`，到右文字12px；上文件名15px / w500 / 行高20px / `textPrimary`，下4px状态13px / w400 / 行高18px，上传中 `textSecondary`、成功 `feedbackSuccess`、失败 `feedbackError`（待校准）。文件名换行或截断方式（待校准）。
    > 21b为成功文件行，下8px（待校准）说明“A utility bill, bank statement or lease from the last 3 months.”，15px / w400 / 行高20px / `textSecondary`。点击文件行暂预览；替换入口为行右20px图标、44px点击区（资源名与交互待校准），替换成功前保留旧文件；上传失败原地重试，不影响地址。
11. **Continue：**底部按通用§6；除邮编外的地址必需项有效且一份证明确实上传成功才可用（待校准）。点击进入§4，复核编辑回复核（待校准）。本页一份证明与审核后多项补件不同，不把文件“已选择”当成“已上传”。

### §4 税务居民页（22，含32/32b/22c）

1. **页面与标题：**底 `bgBase`、左右16px，返回§3并保留全部组（待校准）。正文标题顶缘距返回按钮点击区域底缘14px；标题“Tax residency”，28px / w700 / 行高33px / `textPrimary`、左对齐；下8px说明“Please provide your latest tax residency details.”，15px / w400 / 行高20px / `textSecondary`。说明底下24px为首组内容。导航复用 `EzbScaffold` + `EzbAppBar`，安全区下方留7px。
2. **组标题：**只有一组时不显示编号标题（待校准）；新增后每组先显示“Tax residency 1”“Tax residency 2”等，17px / w500 / 行高23px / `textPrimary`。第2组起同一行右侧 `trash2`20×20px / `feedbackError`，44×44px点击区、右缘对齐内容区（待校准）；首组不可删也不占删除按钮位置。组标题下12px为国家字段（待校准）。
3. **Tax country：**同§1第5条选择字段，标签“Tax country”、右 `chevronDown`20px / `iconSecondary`；值为该组税务居民国，不自动等于居住国。初始是否预填居住国（待校准）；整项点击打开国家选择器，确认后仅改本组。
4. **有/无 TIN 选项：**国家字段下16px，左“I have a TIN”、右“I don’t have a TIN”；Chip排版和选中颜色同§1第3条，项间8px，互斥单选；切换原地展开相应内容，不跳转。未选前是否显示TIN字段（待校准）。
5. **有 TIN 时：**Chip组底下16px为“TIN”输入字段，同普通字段规格，值17px / w400 / 行高23px / `textPrimary`；空占位使用 `textTertiary`。输入按所属国家校验，格式、最大长度（待校准）。切到无TIN后隐藏此项、暂存值但不提交（待校准）。
6. **无 TIN 时：**Chip组底下24px为“Why not?”，17px / w500 / 行高23px / `textPrimary`；其下12px开始三条原因行，自上而下“My country doesn’t issue TINs”“I’ve applied but haven’t received one”“Another reason”。
   > 每行铺满、底 `bgSurface2`、圆角16px、内边距16px、文字17px / w500 / 行高23px / `textPrimary`，右22px圈，文字距圈至少14px，行间12px。无副文时最小高55px（待校准）；选中底 `bgBrandSelected`、圈 `iconBrand`、勾14px/`iconOnBrand`（待校准）。仅单选一项，无TIN本身不阻断开户。
7. **其他原因输入（32b）：**仅选Another reason时，第三原因行下12px展开“Tell us why”，普通字段规格，空占位“Type your reason”。填写后才视为该组完整（待校准），最大长度和错误文案（待校准）；切换其他原因时隐藏并暂存解释、不提交隐藏值（待校准）。
8. **新增另一组：**当前组最后内容下16px为一行 `plus`20px / `iconBrand`，右距8px文案“Add another tax residency”，15px / w500 / 行高20px / `textBrand`，整行点击区至少44px高（待校准）；下4px辅助“Only if you are tax resident in more than one country.”，13px / w400 / 行高18px / `textSecondary`（待校准）。
   > 点击后在下一组位置新增空组，不继承上组TIN；组间24px，最多五组。五组时隐藏新增入口（待校准）。点击某组删除按钮直接删该组并重编号、不二次确认（待校准）；首组始终保留，重复国家暂作错误提示（待校准）。
9. **Continue：**固定底部主操作；每组国家和TIN状态明确，有TIN填有效值，无TIN选原因，“其他”填解释后才可用（待校准）。可接受合法无TIN原因，不要求用户伪造税号；点击进入《05-确认与结果.md》§1，复核编辑则直返复核（待校准）。错误就近展示并聚焦第一处，保留其他完整组。
