# Flow 04 · 关于你 UI 和交互说明

> **范围：**就业页17及自雇31/无业17b、用途与资金来源19、住址与证明21/21b、税务居民22及无TIN32/其他原因32b/多组22c、手机号收集22d。
>
> 颜色使用《../Color/AppColor.md》中当前主题对应的语义色。px 为逻辑像素；文字高度随内容撑开，预估项标“（待校准）”。
> 文案与申请恢复规则见[本目录说明](README.md#文案与申请恢复)。

### §1 工作与收入页（17，含31/17b）

1. **页面与返回：**导航复用 `EzbScaffold` + `EzbAppBar`；系统返回与可见返回执行相同业务动作。从身份核验完成页进入，底 `bgBase`，内容左右16px、长表单可滚动；返回身份核验完成页。从提交前复核进入编辑时，返回目标改为复核页。 支持200%字号，正文可滚动，底部操作不遮挡字段。
2. **标题：**正文标题顶缘距返回按钮点击区域底缘14px；“Your work”，28px / w700 / 行高33px / `textPrimary`、左对齐；标题底向下24px开始就业类型选项。
3. **就业类型行：**从左至右为“Employed”“Self-employed”“Not employed”，单选。每枚Chip文字15px / w500 / 行高20px、左右内边距16px/上下11px、视觉高42px、圆角为高度一半，点击区至少44px高；横向和换行间距均8px，按内容自然换行，不拉成三等分。
   > 未选底 `bgSurfaceRaised`、字 `textPrimary`；选中底 `brandPrimary`、字 `textOnBrand`。首次进入默认选中Employed，并显示Employer details字段组。点击不同类型只替换下方组，不清空其他类型暂存草稿；提交仅使用当前类型的数据。
4. **字段组标签：**Chip组底下24px为“Employer details”/“Business details”/“Your situation”，依当前类型替换；13px / w500 / 行高18px / `textTertiary`，左对齐，底到首字段12px。
   > 本页受雇、自雇及无业各信息项的值文本允许换行，最多显示3行，超出部分显示省略号；容器随实际显示行数增高，保留原内边距与项间距。带右侧箭头时，文字在箭头前的可用宽度内换行，不与箭头重叠。省略仅影响展示，不截短原始值。
5. **受雇时的 Industry：**组内第一项，铺满内容区、圆角16px、底 `bgField`、左右16px/上下14px、最小高71px；标签“Industry”13px / w400 / 行高18px / `textSecondary`；下2px值17px / w500 / 行高23px / `textPrimary`，空时占位用 `textTertiary`。右 `chevronDown`22×22px / `iconSecondary`，右距16px、距文字至少8px；点击整项打开行业选项，确认后原地写回。
6. **受雇时的 Occupation：**Industry底下12px；同字段排版，标签“Occupation”。暂按自由文本、无下拉图标；若改为字典选择需校准后同步形态，不因示例“Designer”推定唯一选项。
7. **受雇时的 Employer name：**前字段下12px，标签“Employer name”，值为可输入雇主名称；沿用前述字段尺寸和颜色，不使用示例公司作为默认值。
8. **受雇时的 Employer registered address：**前字段下12px，标签同名，自由输入注册地址；值17px / w500 / 行高23px / `textPrimary`；字段仍左右16px/上下12px。
9. **受雇时的 Annual income：**前字段下12px，标签“Annual income”，右侧选择箭头与Industry相同；选择年收入区间，不手填精确收入。区间显示17px / w500 / 行高23px，示例“US$50,000 – 80,000”仅为展示例子，完整区间名单后续再补。
10. **切换自雇（31）：**字段组在相同位置改为Business details，自上而下为“Nature of business”“Trading name”“Industry”“Country of operation”“Annual income”，项间12px，所有标签/值/容器样式与上文相同。
    > 前两项分别输入业务性质和经营名称、无尾随箭头；Industry、Country of operation及Annual income为选择字段。经营国家不自动等于居住国。不同时保留受雇字段的视觉空位，不将隐藏的雇主资料作为自雇必填项。
11. **切换无业（17b）：**字段组在相同位置改为Your situation；依次“Current status”“Main source of income”“Annual income”，项间12px。前两项暂按选择字段，收入字段仍选择区间；每项铺满内容区、最小高71px、底 `bgField`、圆角16px、左右16px/上下12px；标签13px / w400 / 行高18px / `textSecondary`，下4px为值17px / w500 / 行高23px / `textPrimary`，空占位 `textTertiary`；右 `chevronDown`20px / `iconSecondary`，右距16px。
12. **Continue：**固定底部操作区铺满屏宽，底 `bgBase`，左右16px、顶部16px、底部为设备安全区+8px；主按钮铺满区内宽，最小高56px、圆角28px、左右内边距16px，文字17px / w600 / 行高23px、居中，正常底 `brandPrimary` / 字 `textOnBrand`，禁用底 `bgDisabled` / 字 `textDisabled`；文字换行可增高，禁用不可点击，处理中阻止重复触发；按钮读屏名称与文案一致，处理状态可播报。未选择类型或当前显示的必需字段不完整时禁用，填写有效后启用。初步按当前分组所有项必填；点击校验当前组，错误就近显示，保留输入。
    > 正常路径进入§2；从复核编辑进入时确认后直接回复核，不重走后续组。行业、国家及收入区间选择器按《02-开始开户与资格判定.md》§3的搜索和Done确认交互；完整选项及各字段是否必填待后续补充。

### §2 用途、资金来源与活动档位页（19）

1. **页面与标题：**导航复用 `EzbScaffold` + `EzbAppBar`；系统返回与可见返回执行相同业务动作。底 `bgBase`、左右16px，返回键返回§1；正文标题顶缘距返回按钮点击区域底缘14px；标题“How will you use it?”，28px / w700 / 行高33px / `textPrimary`，左对齐。
2. **用途标题：**页面标题底下24px为“Main purpose (select all that apply)”，17px / w500 / 行高23px / `textPrimary`；标题下12px为用途Chip组。
3. **用途Chip组：**从左至右、满行换行，顺序“Savings”“Investment”“Everyday payments”“Crypto on/off ramp”；文字15px / w500 / 行高20px，左右16px/上下11px，视觉高42px、圆角21px、点击区至少44px高，横纵间距8px；未选底 `bgSurfaceRaised` / 字 `textPrimary`，选中底 `brandPrimary` / 字 `textOnBrand`。首次进入时用途、资金来源与活动档位均不预选。用途可独立多选，点击已选项取消，不固定设计示例的选中值。
4. **资金来源标题：**用途组最末行底缘向下24px为“Source of funds (select all that apply)”，17px / w500 / 行高23px / `textPrimary`；下12px开始多选Chip。
5. **资金来源Chip组：**依次“Salary”“Business income”“Pension / social security”“Rental income”“Investment income”“Inheritance”；从左至右排满再换行，样式与上组相同，操作互不影响用途组。可多选。
6. **活动档位标题：**资金来源组底下24px为“How much do you expect to move each month?”，17px / w500 / 行高23px / `textPrimary`，允许两行；标题底下12px开始第一条档位行。
7. **Low 行：**底 `bgSurface2`、圆角16px、内边距16px、最小高77px，内部左文字组占余宽，右选择圈22×22px，圈右距16px、距文字至少14px。主文“Low”，17px / w500 / 行高23px / `textPrimary`；下2px副文“Under 10 payments · under US$10k in total”，15px / w400 / 行高20px / `textSecondary`。无左图标，不留空白占位。
8. **Medium 行：**前行底下12px，同布局；主文“Medium”，副文“10–50 payments · US$10k – 50k in total”。
9. **High 行：**前行底下12px，同布局；主文“High”，副文“Over 50 payments · over US$50k in total”。三行互斥选择，未选圈 `bgControlOff`；选中行底 `bgBrandSelected`、圈 `iconBrand`、勾14px/`iconOnBrand`，不加描边。再次点击已选行不取消。不另加精确数字输入框。
10. **Continue：**固定底部操作区铺满屏宽，底 `bgBase`，左右16px、顶部16px、底部为设备安全区+8px；主按钮铺满区内宽，最小高56px、圆角28px、左右内边距16px，文字17px / w600 / 行高23px、居中，正常底 `brandPrimary` / 字 `textOnBrand`，禁用底 `bgDisabled` / 字 `textDisabled`；文字换行可增高，禁用不可点击，处理中阻止重复触发；按钮读屏名称与文案一致，处理状态可播报，内容区可滚动并露出High行；用途与资金来源各至少一项、活动档位恰有一项才可用，否则禁用。正常进入§3，复核编辑确认后直接回复核页；不默认替用户选中示例档位。

### §3 住址与地址证明页（21，含21b）

1. **页面与标题：**导航复用 `EzbScaffold` + `EzbAppBar`；系统返回与可见返回执行相同业务动作。底 `bgBase`、左右16px，返回§2。正文标题顶缘距返回按钮点击区域底缘14px；标题“Your home address”，28px / w700 / 行高33px / `textPrimary`、左对齐；下8px说明“Where you actually live. We’ll ask for one document that shows it.”，15px / w400 / 行高20px / `textSecondary`。 支持200%字号，正文可滚动，底部操作不遮挡字段。
2. **Street address：**说明底下24px。字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下12px，最小高71px；标签“Street address”，13px / w400 / 行高18px / `textSecondary`；下2px为输入值，17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`；输入实际街道/门牌/房号，不作示例默认值；值可多行，字段自然增高，不裁切。
   > 常规与聚焦均无边框，聚焦不改变背景及标签颜色；错误底 `bgErrorTint`，标签及辅助文字 `feedbackError`，无错误边框；辅助文字13px / w400 / 行高18px、距值4px，内容自撑。禁用底 `bgDisabled`、字 `textDisabled`，只读保持正常字色。
3. **City：**前字段底下12px，标签“City”，字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下12px，最小高71px；标签13px / w400 / 行高18px / `textSecondary`，下2px为值17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`；无尾随箭头；不根据地址字符串擅自补城市。
4. **Postal code (optional)：**前字段下12px，字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下12px，最小高71px；标签13px / w400 / 行高18px / `textSecondary`，下2px为值17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`；可留空，留空不阻断本页继续。
5. **Country：**前字段下12px，字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下12px，最小高71px；标签13px / w400 / 行高18px / `textSecondary`，下2px为值17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`；右 `chevronDown`22px / `iconSecondary`；首次进入预填已确认居住国，允许修改。不能悄悄以护照国籍覆盖本值。
6. **Proof of address 标签：**国家字段底下24px，“Proof of address”，13px / w500 / 行高18px / `textTertiary`；下12px为首个上传入口。
7. **Take a photo：**位于Proof of address标签下12px，按钮铺满内容宽，底 `bgSurface2`、无边框、最小高56px、圆角28px、左右内边距24px；文案“Take a photo”，17px / w600 / 行高23px / `textPrimary`，水平和垂直居中，无图标。点击打开相机，取消回本页不清地址。
8. **Choose from photo library：**前按钮下12px，按钮尺寸、背景、圆角及文字样式同上；文案“Choose from photo library”，居中，无图标。点击系统相册，仅选择一份证明，取消保持原状态。
9. **Choose a file：**前按钮下12px，样式同上；文案“Choose a file”，居中，无图标。点击文件选择器。本页地址证明允许PDF/JPG/PNG，单份最大10MB；格式或超限错误不能显示为上传成功。
10. **已上传状态（21b）：**上传成功后，保留Proof of address标签，在标签下12px用一张提示卡替换三个上传按钮。
    > **卡片：**铺满内容宽，底 `bgGlass`、无边框、圆角16px、内边距16px；玻璃视觉模糊13，降低透明度时使用 `bgSurface2` 实底。卡片随文字内容增高。
    > **左侧图标：**`fileText`20×20px / `iconBrand`，与右侧文字组顶端对齐，间距12px。
    > **右侧标题：**“{FileName} uploaded”，17px / w600 / 行高23px / `textPrimary`；文件名使用实际上传文件名，uploaded与文件名同属标题，不另加成功状态行。
    > **标题下方说明：**距标题底缘4px；“A utility bill, bank statement or lease from the last 3 months.”，15px / w400 / 行高20px / `textSecondary`，在卡片内自然换行。
    > 上传中及失败反馈的具体表现待后续补；失败保留地址，允许重试。仅实际上传成功后显示本卡片并参与Continue可用性判断。
11. **Continue：**固定底部操作区铺满屏宽，底 `bgBase`，左右16px、顶部16px、底部为设备安全区+8px；主按钮铺满区内宽，最小高56px、圆角28px、左右内边距16px，文字17px / w600 / 行高23px、居中，正常底 `brandPrimary` / 字 `textOnBrand`，禁用底 `bgDisabled` / 字 `textDisabled`；文字换行可增高，禁用不可点击，处理中阻止重复触发；按钮读屏名称与文案一致，处理状态可播报；除邮编外的地址必需项有效且一份证明确实上传成功才可用。点击提交地址与证明，并由后台重新检查居住国准入；通过后正常进入§4，复核编辑则直接回复核。不通过时沿用《02-开始开户与资格判定.md》的国家准入分支，包括§5巴林居民的仅创建客户号规则。请求失败保留地址与已上传证明，允许重试。本页一份证明与审核后多项补件不同，不把文件“已选择”当成“已上传”。

### §4 税务居民页（22，含32/32b/22c）

1. **页面与标题：**导航复用 `EzbScaffold` + `EzbAppBar`；系统返回与可见返回执行相同业务动作。底 `bgBase`、左右16px，返回§3。正文标题顶缘距返回按钮点击区域底缘14px；标题“Tax residency”，28px / w700 / 行高33px / `textPrimary`、左对齐；下8px说明“Please provide your latest tax residency details.”，15px / w400 / 行高20px / `textSecondary`。说明底下24px为首组内容。 支持200%字号，正文可滚动，底部操作不遮挡字段。
2. **组标题：**只有一组时不显示编号标题；新增后每组先显示“Tax residency 1”“Tax residency 2”等，13px / w700 / 行高33px / `textPrimary`。第2组起同一行右侧显示删除按钮：按钮与点击区均为38×38px，圆形背景 `bgControlGhost`，内部 `trash2`24×24px / `iconPrimary`，水平和垂直居中；按钮右缘对齐内容区；首组不可删也不占删除按钮位置。组标题下12px为国家字段。
3. **Tax country：**字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下14px，最小高71px；标签13px / w400 / 行高18px / `textSecondary`，下2px为值17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`；右 `chevronDown`22×22px / `iconSecondary`，右距16px，与值至少8px；标签为“Tax country”，值为该组税务居民国，不自动等于居住国。首次进入只显示一组，Tax country为空；整项点击打开国家选择器，确认后仅改本组。
   > 常规与聚焦均无边框，聚焦不改变背景及标签颜色；错误底 `bgErrorTint`，标签及辅助文字 `feedbackError`，无错误边框；辅助文字13px / w400 / 行高18px、距值4px，内容自撑。禁用底 `bgDisabled`、字 `textDisabled`，只读保持正常字色。
4. **有/无 TIN 选项：**国家字段下16px，左“I have a TIN”、右“I don’t have a TIN”；每枚Chip文字15px / w500 / 行高20px、左右16px/上下11px、视觉高42px、圆角21px、点击区至少44px高，项间8px；未选底 `bgSurfaceRaised` / 字 `textPrimary`，选中底 `brandPrimary` / 字 `textOnBrand`，互斥单选；切换原地展开相应内容，不跳转。首次进入默认选中“I have a TIN”，显示空的TIN输入字段。
5. **有 TIN 时：**Chip组底下16px为“TIN”输入字段，字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下14px，最小高71px；标签13px / w400 / 行高18px / `textSecondary`，下2px为值17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`。TIN明文展示，不掩码。切到无TIN后隐藏此项、暂存值但不提交。
6. **无 TIN 时：**Chip组底下24px为“Why not?”，17px / w500 / 行高23px / `textPrimary`；其下12px开始三条原因行，自上而下“My country doesn’t issue TINs”“I’ve applied but haven’t received one”“Another reason”。
   > 每行铺满、底 `bgSurface2`、圆角16px、内边距16px、文字17px / w500 / 行高23px / `textPrimary`，右22px圈，文字距圈至少14px，行间12px。无副文时最小高55px；选中底 `bgBrandSelected`、圈 `iconBrand`、勾14px/`iconOnBrand`。首次切到无TIN时不预选原因；仅单选一项，无TIN本身不阻断开户。
7. **其他原因输入（32b）：**仅选Another reason时，第三原因行下12px展开“Tell us why”，字段铺满内容区、圆角16px、底 `bgField`、左右16px/上下14px，最小高71px；标签13px / w400 / 行高18px / `textSecondary`，下2px为值17px / w500 / 行高23px / `textPrimary`，空占位用 `textTertiary`；空占位“Type your reason”。填写非空原因文字后才视为该组完整，最多显示3行，超出显示省略号。
